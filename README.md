# Лапы на страже! — Doggo Tower Defense

Браузерная tower defense про отряд собак, защищающий корзину с лакомствами от белок. Игра сделана на Phaser 3, TypeScript и Vite.

## Запуск локально

Требуется Node.js 20 или новее.

```sh
npm install
npm run dev
```

Откройте URL, который выведет Vite. Для production-сборки выполните `npm run build`; локально посмотреть её можно через `npm run preview`.

## Как играть

- Выберите бигля, овчарку или корги и нажмите на свободную траву, чтобы поставить защитника.
- Нажмите «Начать волну». Собаки автоматически атакуют белок теннисными мячами.
- За побеждённых белок и завершённые волны начисляются косточки.
- Выберите установленную собаку и нажмите «Улучшить», чтобы повысить её урон и дальность.
- Не пропускайте белок к корзине: потеряйте все 10 жизней — и игра закончится.
- Используйте кнопки паузы и скорости, чтобы управлять темпом игры.

## Структура

- `src/scenes/` — загрузочная сцена и игровой цикл.
- `src/entities/` — собаки-защитники, белки и снаряды.
- `assets/` — SVG-заглушки игровых изображений.
- `.github/workflows/` — проверка сборки и публикация на GitHub Pages.

При push в `main` GitHub Actions собирает игру и публикует `dist/` на GitHub Pages. Для включения публикации в репозитории выберите **Settings → Pages → Build and deployment → GitHub Actions**.

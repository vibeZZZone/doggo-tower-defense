# Лапы на арене! — Dog Brawl

Браузерный аренный файтинг на Phaser 3, TypeScript и Vite. Бисквит сражается с компьютерным соперником Грозой на платформенной арене: наносит урон, отбрасывает противника и старается выбить его за край. Бой продолжается до потери трёх запасов жизни.

## Запуск локально

Требуется Node.js 20 или новее.

```sh
npm install
npm run dev
```

Откройте URL, который выведет Vite. Для production-сборки выполните `npm run build`; локально посмотреть её можно через `npm run preview`.

## Управление

- `A` / `D` — двигаться влево / вправо.
- `W` или `↑` — прыгнуть.
- `J` — удар лапой.
- `K` — суперлай с большим радиусом и отбрасыванием.
- На телефоне доступны сенсорные кнопки под ареной.

Чем выше процент урона соперника, тем дальше его отбрасывают попадания. Используй прыжки и платформы, чтобы сбросить соперника за границы арены. Матч можно начать заново кнопкой «Заново».

## Структура

- `src/scenes/` — загрузочная сцена, арена, бой и поведение CPU.
- `assets/` — SVG-портреты собак и графика снарядов.
- `.github/workflows/` — проверка сборки и публикация на GitHub Pages.

При push в `main` GitHub Actions собирает игру и публикует `dist/` на GitHub Pages. Для включения публикации в репозитории выберите **Settings → Pages → Build and deployment → GitHub Actions**.
